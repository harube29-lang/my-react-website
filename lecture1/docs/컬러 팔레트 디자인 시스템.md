# 컬러 팔레트 디자인 시스템

> 출처: Cornerstone Interactive 웹사이트 이미지 분석 (2026-06-08)

---

## CSS 변수 정의

```css
:root {
  /* Primary */
  --color-primary:    #E85C1E;   /* 오렌지 포인트 — 로고, 아이콘, 강조 */

  /* Dark */
  --color-dark:       #1C1C1C;   /* 헤드라인, 핵심 텍스트 */

  /* Backgrounds */
  --color-bg:         #F4F4F2;   /* 페이지 전체 배경 (아이보리-그레이) */
  --color-surface:    #FFFFFF;   /* 카드, 내비게이션 배경 (순백) */
  --color-overlay:    #EBEBEB;   /* 구분 배경, 오버레이 레이어 */

  /* Text */
  --color-text:       #555555;   /* 본문 텍스트 (내비 링크 등) */
  --color-muted:      #999999;   /* 보조·푸터 텍스트 */

  /* Border / UI */
  --color-border:     #DDDDDD;   /* 카드 테두리, 구분선 */
  --color-arrow:      #888888;   /* 비활성 슬라이드 화살표 */
}
```

---

## 컬러 스와치

| 역할             | 변수명                | HEX       | 사용 비율 |
|------------------|----------------------|-----------|----------|
| Primary (Orange) | `--color-primary`    | `#E85C1E` | 5%       |
| Dark             | `--color-dark`       | `#1C1C1C` | 12%      |
| Background       | `--color-bg`         | `#F4F4F2` | 60%      |
| Surface          | `--color-surface`    | `#FFFFFF` | 20%      |
| Overlay          | `--color-overlay`    | `#EBEBEB` | —        |
| Text             | `--color-text`       | `#555555` | 2%       |
| Muted            | `--color-muted`      | `#999999` | 1%       |
| Border           | `--color-border`     | `#DDDDDD` | —        |

## MUI Theme 적용 예시

```js
import { createTheme } from '@mui/material/styles'

const theme = createTheme({
  palette: {
    primary:   { main: '#E85C1E' },
    secondary: { main: '#1C1C1C' },
    background: { default: '#F4F4F2', paper: '#FFFFFF' },
    text: {
      primary:   '#1C1C1C',
      secondary: '#555555',
      disabled:  '#999999',
    },
    divider: '#DDDDDD',
  },
})
```

## 디자인 특징

- **모노크롬 + 싱글 포인트 컬러** 구조: 흰색·밝은 회색의 넓은 여백 위에 오렌지 `#E85C1E` 하나로 브랜드 강조
- 고급 자동차 브랜드 특유의 **절제미와 신뢰감** 표현
- 시선이 자연스럽게 오렌지 요소로 집중되는 **명확한 위계**
